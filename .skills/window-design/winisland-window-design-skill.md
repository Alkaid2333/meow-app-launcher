# WinIsland 窗口界面设计 Skill

> 本 skill 提供一套**框架无关的窗口界面设计规格**，源自 WinIsland v1.3.0 的实际设计。
> 所有尺寸均为逻辑像素（px），实际渲染时统一乘以全局缩放系数 `global_scale`（DPI 适配）。
> 色值使用 RGBA / RGB 描述，可直接映射到任何设计体系。

---

## 1. 设计总览

WinIsland 的窗口界面由三部分组成，各自独立、可单独还原：

| 部分 | 定位 | 关键设计点 |
|---|---|---|
| **灵动岛本体** | 主悬浮窗口 | 无边框透明胶囊、G3 连续曲率圆角、双态尺寸、边缘停靠与隐藏 |
| **配置 GUI** | 独立设置窗口 | 侧边栏导航 + 分组卡片内容区、macOS 风格窗口控制、语义化配色 |
| **托盘** | 系统托盘入口 | 主题自适应图标、4 项菜单、可见性动态切换 |

设计哲学贯穿三部分：
1. **一切尺寸可缩放**——单一 `global_scale` 控制全局（对应 DPI 缩放），布局不写死像素。
2. **状态驱动外观**——可见/隐藏/展开/折叠/悬停都是状态，外观由状态推导。
3. **视觉层级分明**——背景、内容、覆盖层、描边四层分离。

## 2. 灵动岛本体窗口设计

### 2.1 窗口形态规格

| 属性 | 设计规格 | 说明 |
|---|---|---|
| 背景 | 完全透明 | 窗口本身无背景，内容由岛体绘制 |
| 边框 | 无系统边框 / 无标题栏 | 完全自绘外观 |
| 层级 | 始终置顶 | 常驻所有普通窗口之上 |
| 焦点 | 不抢焦点 | 打开/交互时不激活窗口本身 |
| 任务栏 | 不显示 | 从任务栏/程序坞隐藏 |
| 尺寸 | 内容外扩安全边距 `PADDING = 80px` | 为运动模糊、阴影、边界位移预留空间 |
| 离屏间距 | `TOP_OFFSET = 10px` | 岛体到屏幕边缘的默认距离 |
| 移动 | 支持拖拽（右键拖动整体定位） | 位置偏移持久化 |

### 2.2 岛体几何：G3 连续曲率圆角

**设计目标**：复刻 iOS 灵动岛的"三段式"曲率——圆角不是简单圆弧，而是**从直线平滑过渡到圆弧、再平滑收回**的连续曲率路径（G3 连续）。

**设计参数**：
- 圆角混合范围 `extent = 0.3`（圆角过渡区占圆角半径的比例）
- 过渡区用 4 次多项式混合曲线（满足位置/斜率/曲率/曲率变化率连续）
- 主弧段用 1/4 圆弧（权重 √2/2 的圆锥曲线）
- 整条路径 = 4 个 G3 角 + 4 条直线边

**形态规则**：
- 圆角半径钳制：`radius = clamp(r, 0, min(宽/2, 高/2))`
- 紧凑态：胶囊形，圆角 = 高度/2
- 展开态：固定大圆角（默认 32px）

**可还原实现提示**（任意矢量图形库）：将单位角（1×1 区域）按 extent 分段采样——过渡区用多项式曲线点列，主弧用圆弧——再把单位角仿射缩放到实际圆角半径。路径按 (rect, radius) 缓存。

### 2.3 双态尺寸规格

| 状态 | 宽度 | 高度 | 圆角 | 内容 |
|---|---|---|---|---|
| 紧凑态 | `base_width` | `base_height` | `base_height / 2`（胶囊） | 迷你歌词 / 小组件 / 通知 / 音量 |
| 展开态 | `expanded_width` | `expanded_height` | `32px` | 音乐页 / 小组件页 |

- 尺寸由配置提供，支持用户自定义，且全部乘 `global_scale`。
- 宽度可变场景：歌词文字自适应——歌词宽度 = 文字自然宽 + 60px 余量，钳制在 `[base_width + 35, MAX_LYRIC_WIDTH = 700px]`；超长歌词启用滚动时取固定宽度。
- 两个状态之间由动画衔接（见动画 skill），内容用**双 alpha 交叉淡化**切换。

### 2.4 停靠系统（Dock）

| 停靠位置 | 描述 |
|---|---|
| TopCenter / BottomCenter | 水平居中，顶部/底部 |
| TopLeft / TopRight | 顶部左/右角 |
| BottomLeft / BottomRight | 底部左/右角 |

**自动停靠规则**（位置随显示器自适应）：
1. 以岛体中心为锚点计算展开后的水平边界是否越出显示器 → 决定左/中/右。
2. 以展开高度是否越出底部 → 决定上/下。
3. 组合出 6 个停靠位；支持用户手动偏移微调（`position_x/y_offset`，右键拖拽写入）。

### 2.5 隐藏系统

**三态隐藏**（可叠加）：

| 状态 | 触发 | 行为 |
|---|---|---|
| auto（闲置隐藏） | 悬停离开 + 闲置超时（默认 5s） | 滑向最近屏幕边缘 |
| fullscreen（全屏隐藏） | 前台全屏应用 + 光标隐藏 | 自动收起，媒体播放中豁免 |
| manual（手动隐藏） | 上滑拖拽 | 跟随拖拽进度 |

**设计规则**：
- **最近边缘判定**：比较岛体到上/下/左/右四边的距离，取最小。
- **隐藏位移**：沿边缘法线滑出，露出"隐藏可见宽度"（默认 5px，可配置 0~400px；设为 0 时保留 **1px 热区**）。
- **热区唤起**：隐藏后保留 1px 可命中区域，悬停即弹出（带弹回动画）。
- **全屏豁免**：媒体播放中不因全屏隐藏（避免打扰）。
- 隐藏时暂停一切周期刷新（功耗设计，见动画 skill）。

### 2.6 内容层级结构

```
窗口（透明画布，PADDING 安全区）
└─ 岛体（G3 圆角路径裁剪）
   ├─ 背景层     # 4 种风格：纯色 / 毛玻璃 / 动态封面 / 桌面模糊
   ├─ 紧凑层     # 迷你歌词 / 小组件 / 通知 / 音量（与展开层 alpha 交叉淡化）
   ├─ 展开层     # 音乐页 + 小组件页（两页并排，水平滑动切换）
   ├─ 覆盖层     # 通知横幅、音量指示（临时叠加，可改变岛体尺寸）
   └─ 描边       # 1px 半透明白描边（紧凑 30 / 其他 40 alpha）
```

**迷你态（紧凑层）布局**：
- 左侧：可选封面（方形或圆形，默认 72px 基准）或小组件槽位
- 中部：迷你歌词（单行，超长滚动）或通知/音量
- 右侧：小组件槽位 / 频谱
- 左右侧小组件按槽位网格挂载（槽位宽 1~2 格，高 1~2 格）

**展开态（音乐页）布局**（基准比例，全部乘 scale）：

```
+--------------------------------------------------+
|  [封面 72×72]  标题（粗体, 14px 基准）     →      |
|   @(24,24)     艺术家（次级色, 12px 基准）        |
|                                                  |
|   ── 进度条 ──────────  00:00 / 03:45            |
|   @y=114 左/右各让出 36+4 给时间文本              |
|                                                  |
|      [上一首]   [播放/暂停]   [下一首]            |
|      @y=156  播放键居中(命中40)  ±75px(命中36)   |
|                                                  |
|   ▁▃▅▂ 频谱条（底部，高度随展开进度缩放）         |
+--------------------------------------------------+
```

- 封面区：`img_x = 24`、`img_y = 24`、`img_size = 72`
- 文字区：`text_x = img_x + 72 + 16`，标题基线 `img_y + 26`
- 进度条：`bar_y = img_y + 72 + 18`，左右时间文本宽 `36`、间距 `4`
- 控制行：`btn_cy = bar_y + 42`；播放键居中，上一首/下一首 ±75
- 右箭头指示器：右上角（`x = 宽 - 7.5`），滑动切换时淡出
- 频谱条：右侧纵向排列（6 条），高度随展开进度缩放
- 小组件页：与音乐页并排，`page_shift = view_offset × 当前宽度` 水平滑入

**覆盖层（通知/音量）**：临时取代迷你内容，通知可带图标+标题+正文，音量显示进度条，显示期间岛体可临时加宽，结束后恢复。

### 2.7 命中与穿透

- **命中区** = 岛体 G3 圆角路径内部（含隐藏时的 1px 热区）。
- 命中区外鼠标事件**完全穿透**到下层窗口。
- 交互热区应大于视觉尺寸（控制按钮视觉小、命中区大：如播放键视觉 ~24 命中 40）。

### 2.8 背景风格（4 种）

| 风格 | 设计描述 |
|---|---|
| default | 纯黑底色 + 白描边 |
| glass | 实时毛玻璃：捕获岛体后方屏幕内容 → 模糊（σ≈40）→ 深色乘性变暗 |
| dynamic | 用主内容图（如专辑封面）模糊放大后缓慢旋转漂移作底，压暗遮罩；无图时回落 glass |
| mica | 桌面整体模糊采样，按岛体区域裁剪 |

设计原则：背景永远"压暗"（保证白字可读），遮罩 alpha 约 110~130。

## 3. 配置 GUI 设计

### 3.1 窗口规格

| 属性 | 规格 |
|---|---|
| 窗口尺寸 | 760 × 680 px |
| 窗口圆角 | 16 px |
| 主题 | 深色 / 浅色（跟随系统，可手动覆盖） |

### 3.2 布局框架

```
+----------------------------------------------+
| ⭘ ⭘ ⭘   [侧边栏 184] |   内容区            |
| 红绿灯        |             |                |
|               |  图标+标签  |  分组卡片区      |
|               |  导航行     |  (可滚动)       |
|               |  ×5        |                |
+----------------------------------------------+
```

- 侧边栏宽 `184px`；内容区 = 窗口宽 − 184。
- 左侧顶部：macOS 风格窗口控制按钮（见 3.3）。
- 内容区顶部：页面导航（返回/前进，28×28 按钮，间距 4）。
- 内容区 = 分组卡片列表，可垂直滚动。

### 3.3 侧边栏设计

**窗口控制（红绿灯）**：
- 三个圆形按钮，圆心 `(20,20) / (40,20) / (60,20)`，半径 `6px`，命中半径 `8px`
- 配色（聚焦时）：红 `#FF5F57` / 黄 `#FEBC2E` / 灰 `#7E7E84`；未聚焦时统一浅灰
- 每个按钮：1px 描边 + 0.75px 底偏移投影；悬停显示符号（关闭 × / 最小化 —）
- 约定：红=关闭设置窗口，黄=最小化，灰=未实现/占位

**导航行**：
- 行高 `34px`，起始 y `64px`，间距 2px，内边距 8px
- 结构：图标（22×22）+ 标签文字（13px，选中加粗）
- 选中态：accent 底色圆角行（圆角 7）+ 白字
- 悬停态：半透明底色（alpha 随悬停缓动 0→1）+ 文字变主色
- 图标：每页一枚（一般/音乐/组件/插件/关于）

**页面列表（5 页）**：一般、音乐、组件、插件、关于。

### 3.4 内容区设计（分组卡片）

**分组规格**：
- 内容区左右内边距 `24px`
- 组圆角 `12px`，组内边距 `16px`，组间留白
- 组与组之间、组与分隔之间按行高节奏排列

**行类型**（行高基准 `48px`，SectionHeader 36px）：

| 行类型 | 用途 | 交互 |
|---|---|---|
| SectionHeader | 分组标题 | 无 |
| RowSwitch | 布尔开关 | 拨动开关 |
| RowStepper | 数值调节（±） | 步进按钮 28×28 + 数值区 52px 宽 |
| RowSourceSelect | 来源/选项选择 | 点击弹下拉菜单 |
| RowButton | 动作按钮 | 点击执行 |
| RowLabel | 只读信息 | 无 |
| RowFontPicker | 字体选择 | 打开字体选择器 |
| RowFolderPicker | 目录选择 | 打开目录选择器 |
| RowAppItem | 应用条目（列表项） | 勾选/移除 |

**开关（Toggle）规格**：轨道 `36 × 20`，圆角 `10`，旋钮 `16×16`，内边距 `2`；
开=绿色 `#34C759`（暗色主题下可自定义），关=灰；切换动画用弹性过渡。

**弹窗（Popover）规格**：圆角 `10`，内边距 `5`，行高 `32`；按钮 `112×28` 圆角 `7`；
弹出带透明度渐入动画。

### 3.5 滚动与页面切换

- 滚动条：宽 `4px`，命中宽 `16px`，缩略块最小高 `32px`，顶部留 `8px`、底部留 `8px`
- 滚动采用弹簧物理（近似 stiffness 55 / damping 16），松手惯性滚动
- 页面切换：内容区整页滑动过渡动画（前进/后退方向感知，支持历史栈）
- 数字输入框：点击进入编辑，回车提交，失焦取消

### 3.6 配色 Token（两套主题）

**语义 token**（设计体系，非具体实现）：

`win_bg` / `sidebar_bg` / `group_bg` / `card_highlight` / `text_pri` / `text_sec` / `disabled` / `accent` / `danger` / `toggle_on` / `toggle_off` / `sidebar_hover` / `separator` / `popup_bg` / `popup_border` / `control_bg` / `control_hover` / `control_disabled` / `control_border` / `group_border` / `shadow`

**浅色主题基准**：
- 窗口底 `#F6F6F8`、侧边栏 `#EBEBEE`、分组卡 `#FFFFFF`、卡片高亮 `#E5E5EA`
- 主文字 `#1C1C1E`、次文字 `#5C5C61`、禁用 `#8E8E93`
- 强调色 `#007AFF`（iOS 蓝）、危险色 `#FF3B30`、开关开 `#34C759`
- 分隔线 black 18~26 alpha、描边 black 34 alpha、阴影 black 18 alpha

**深色主题基准**：
- 窗口底/侧边栏为近黑灰（#1C1C1E 系），分组卡略亮，文字反转（白系）
- 强调色保持 `#007AFF`，危险 `#FF3B30`，开关开 `#34C759`
- 弹出层 `#323234`、描边 white 24~40 alpha

**规则**：一律使用语义 token，禁止在页面里写死色值；hover/active 状态用同色系透明度变化。

## 4. 托盘设计

### 4.1 图标

| 属性 | 规格 |
|---|---|
| 主题适配 | 跟随系统亮暗：暗色主题用白色系图标，浅色主题用深色系图标 |
| 提示文本 | 应用名称 |

### 4.2 菜单结构（4 项）

| 顺序 | 菜单项 | 行为 |
|---|---|---|
| 1 | 显示 / 隐藏 | **动态文本**：岛体可见时显示"隐藏"，不可见时显示"显示"；点击切换可见性 |
| 2 | 设置 | 打开配置 GUI 窗口 |
| 3 | 重启 | 退出当前进程并自动重启 |
| 4 | 退出 | 退出应用 |

### 4.3 交互规则

- 单击托盘图标 = 显示/隐藏切换（与菜单第 1 项等价）。
- 菜单文本需随可见性实时更新（状态驱动）。
- 托盘在设置窗口与主窗口之间充当"总控"入口，优先级：主窗口状态为准。

## 5. 跨框架还原指南

### 5.1 三部分还原要点

| 能力 | Web（浏览器） | 桌面原生 | 自绘引擎 |
|---|---|---|---|
| 无边框透明窗口 | 不支持原生，需 Electron/Tauri 或浏览模式 | 平台窗口 API | 平台窗口 API |
| 置顶/不抢焦点/穿透 | 平台层（Tauri 插件等） | 原生 API | 原生 API |
| G3 圆角 | SVG Path / Canvas | 平台路径 API | 矢量路径 |
| 侧边栏布局 | Flexbox 两栏 | 布局容器 | 自绘布局 |
| 语义配色 | CSS 变量 | 主题对象 | 主题结构体 |

### 5.2 还原时的强制规则

1. **全局缩放优先**：所有尺寸先定义"基准值"，再统一乘 `global_scale`；禁止局部写死像素。
2. **状态机先行**：把 可见/展开/隐藏/聚焦/悬停 定义为显式状态，绘制只读状态。
3. **层级四层分离**：背景 / 内容 / 覆盖 / 描边各自独立成层，禁止混合绘制。
4. **语义色**：用 token 而非色值直写，保证两套主题一键切换。
5. **热区大于视觉**：交互命中区域始终比视觉尺寸大（1.2~1.7×）。
6. **可打断**：所有状态切换（展开/隐藏/换页）支持中途反向（与动画 skill 配套）。

### 5.3 最小可验收还原集

- [ ] 一个透明无边框置顶胶囊，G3 曲率圆角，紧凑/展开双态可切换
- [ ] 六向停靠 + 上滑隐藏 + 1px 热区唤起
- [ ] 配置窗口：侧边栏 5 页导航 + 至少 3 种行控件 + 两套主题
- [ ] 托盘：主题自适应图标 + 显示/隐藏动态菜单

## 6. 验收清单（设计还原自查）

- [ ] 所有尺寸乘 `global_scale` 后观感一致（含 DPI 200%）
- [ ] G3 圆角在 100%/150%/200% 缩放无畸变
- [ ] 紧凑 ↔ 展开切换时内容正确交叉淡化
